## 🌟 Principais Funcionalidades

- 🎨 **Design Premium**: Interface moderna com suporte nativo a **Dark Mode** e **Light Mode**, micro-interações e transições suaves.
- ♿ **Acessibilidade (a11y)**: Estrutura HTML semântica, contraste de cores otimizado para leitores de tela e navegação por teclado (W3C/WCAG).
- 📊 **Gráficos Dinâmicos**: Integração com *Chart.js* para visualização de dados de Receita e Base de Clientes.
- 🔐 **Autenticação Segura**: Sistema de Login robusto com verificação em duas etapas (2FA).
- 🚀 **Performance Extrema**: Otimizado para bater notas máximas (95+) no Lighthouse/PageSpeed Insights.
- 🔔 **Notificações**: Sistema de *Toast Notifications* (Sonner) para feedbacks visuais imediatos.

## ⚙️ Como Executar o Projeto

1. **Clone o repositório:**
```bash
git clone https://github.com/Jaosuzart/AdminPanel.git
cd AdminPanel
```

2. **Instale as dependências:**
```bash
npm install
```

3. **Inicie os servidores (Frontend + Backend) simultaneamente:**
```bash
npm run dev
```

> **Acesso:** O Frontend estará disponível em `http://localhost:5173` e o Backend rodando na porta `3333`.

---

## 📈 Scripts Disponíveis no Package.json

| Comando | Descrição |
| :--- | :--- |
| `npm run dev` | Roda o servidor Node e o Vite ao mesmo tempo (ambiente de desenvolvimento). |
| `npm run build` | Gera a build otimizada para produção (Frontend). |
| `npm run preview` | Visualiza a build de produção localmente na sua máquina. |
