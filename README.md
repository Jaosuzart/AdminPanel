# Projeto Dashboard

Dashboard administrativo responsivo inspirado no projeto do curso, recriado com semântica, Bootstrap e JavaScript.

## Tecnologias
- HTML5 semântico
- CSS3
- Bootstrap 5
- JavaScript
- Node.js + Express

## Executar
```bash
npm install
npm start
```

Abra http://localhost:3000

## Boas práticas
Estrutura semântica, CSS separado, JavaScript separado, acessibilidade básica, responsividade e `defer` no script.
